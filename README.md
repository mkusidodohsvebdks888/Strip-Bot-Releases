# Strip Bot · Windows 下载与更新

此仓库只发布 Windows 安装包、更新信息和校验文件。源码在独立私有仓库维护。

## 下载

在 [Releases](https://github.com/mkusidodohsvebdks888/Strip-Bot-Releases/releases/latest) 下载 `Strip-Bot-Setup-版本-x64.exe` 并安装。

首次使用需要安装新版一次。安装后的版本支持 **设置 → 软件更新 → 检查更新 / 下载更新 / 重启并更新**，并在启动后和运行期间定期检查新版本。旧的文件夹便携版需手动下载安装版。

更新不包含个人聊天、配置或 API Key；重启前请保存未发送草稿并完成正在进行的任务。

7-Zip 和 LibreOffice 属于可选工具依赖，需在本机另外安装。安装包自带 Node、Codex 和桌宠运行资源。

第三方许可证随软件提供。桌宠基于 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，代码与美术分别遵守上游许可；大肥鱼形象采用 CC BY-NC-SA 4.0，素材禁止商用。请阅读安装包中的完整原项目说明与许可证。

当前版本未使用 Windows 代码签名证书，系统可能显示未知发布者。
